# Heat & Housing · #30DayMapChallenge 2026

**Live:** https://barisparlatangiller.github.io/

Landing page for my [#30DayMapChallenge](https://30daymapchallenge.com) 2026: 30 interactive maps on urban heat,
housing and land in Germany's eight largest cities, built only from open data. Each day has its own repository,
pipeline (GitHub Actions) and GitHub Pages map; this page links them all and shows what is still to come.

## Update a day

Edit `data/days.json`: set `"status": "live"` and add `url`, `repo`, `thumb` (a 4:3 image in `assets/thumbs/`)
and a one-line `finding`. Push — the page reads the file on load.
